## 1. 手續費設定的新模型（先擴充、不破壞既有程式）

過渡期的規則（1.1 到 3.1 之間，所有任務在同一個 PR 內）：`FeeSettings` 同時帶 `mode`、新增的 `discount`、`wholeLotMinimumFee`、`oddLotMinimumFee`。`discount` 一律從儲存的 feeDiscount 讀取（不管 `mode`）；`FeeSettings(mode: .discount(d))` 的 `discount` 是 d，`.fixedAmount` 時是預設的 10。`parse`、`save`、`summaryText` 與專用頁只用 `discount` 與兩個最低手續費，不讀也不寫 `mode`。過渡期的初始化函式：對外只有 `init(mode:wholeLotMinimumFee:oddLotMinimumFee:)`，由 `mode` 推出 `discount`；`current()` 在固定金額模式下需要同時指定 `mode` 與儲存的折數，用 `FeeSettings` 內部（private 或 fileprivate）的初始化函式完成，不對外開放同時傳 `mode` 與 `discount` 的初始化，避免做出 `mode` 是 6 折而 `discount` 是 2.8 的不一致物件。`FeeCalculator` 在過渡期仍依 `mode` 計算，3.1 才移除固定金額分支。
